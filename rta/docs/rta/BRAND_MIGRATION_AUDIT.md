# Ṛta — Brand Migration Audit

> **Document kind:** classification record for the migration from the former
> “SDC Validator / SDC Tools” identity to **Ṛta**.
> **Date:** 2026-08-06 · **Result:** executed — 104 classified replacements,
> zero validation-semantics changes.

---

## 1. Purpose

The migration from the previous product identity to Ṛta is **semantic, not
mechanical**. Every occurrence of the old product name was classified before
any replacement. This document is the classification record and the
authoritative rule set for future occurrences.

## 2. Classification scheme

| Class | Meaning | Action |
|---|---|---|
| **A — MUST REBRAND** | User-facing product name occurrences | `SDC Validator` / `SDC Tools` → `Ṛta` |
| **B — TECHNICAL TERMINOLOGY — KEEP** | SDC standard terms, rule codes, parser vocabulary | no change |
| **C — TECHNICAL IDENTIFIER — REVIEW** | package/CLI/import/repo identifiers | keep ASCII this phase; `rta` alias added |
| **D — HISTORICAL / BENCHMARK EVIDENCE — PRESERVE** | past phase reports, manifests, golden suites, user data | no change |
| **E — REMOVE** | dead branding, stale copy, build artifacts | removed |

## 3. Class A — must rebrand (executed)

Surfaces migrated from `SDC Validator` / `SDC Tools` to **Ṛta** (104 occurrences):

- **Website** — `site/*.html`, capability pages, `site/assets/js/site.js`
  (header/footer brand, hero terminal `rta check …`, CTAs), `site.css` header.
- **Workspace** — `webui/index.html` (title, meta, brand mark, noscript),
  `webui/assets/js/{app,pages,components,viz,theme}.js`, `app.css`,
  `api_server.py` (banner + module header).
- **Streamlit workspace (legacy)** — `app.py` (page title), `ui/workspace.py`,
  `ui/components.py` (brand spans + nav label), `ui/tab_test_drive.py`,
  `ui/feedback.py`, `ui/__init__.py`.
- **CLI** — `cli.py` headers (`Ṛta v1.3.0 — …`), `--version`, `cmd_web` banner,
  web-command description.
- **Reports** — `reporter.py` page title, footer “Generated by Ṛta”, subtitle.
- **Generator** — generated-SDC header comment “generated by Ṛta”.
- **Docs** — `docs/features/*`, `docs/product/*` (product-name occurrences only;
  CLI examples and technical terminology preserved).
- **Repo presentation** — `README.md` (rewritten — see separate section),
  `CONTRIBUTING.md`, `CHANGELOG.md` header + new Ṛta Foundation entry,
  `Dockerfile` image title label, `__init__.py`/`tests/*` docstrings,
  `custom_rules.py` + example header, `.claude/` agent & skill definitions,
  `benchmarks/README.md`, `benchmarks/run_benchmark.py`,
  `benchmarks/test_ui_app.py`, `support_boundary.py` header.

## 4. Class B — technical terminology kept

Never renamed (examples):

- `SDC`, `SDC file`, `SDC command`, `SDC validation`, `SDC rule`
- rule codes: `SDC-001 … SDC-132`, `CHG-*`
- module names: `checker.py`, `sdc_preprocess.py`, `design_context.py`, …
- API: `check_sdc()`, `analyze_clock_relations()`

**Rule:** the SDC standard is not ours to rename. Branding lives on product
surfaces, not on the standard.

## 5. Class C — technical identifiers (decision record)

| Identifier | Current | Decision | Rationale |
|---|---|---|---|
| CLI entry point | `sdc-tools` | **keep + add `rta` alias** | `rta = cli:main` added to `pyproject.toml`; `sdc-tools` retained for backward compatibility and CLI-contract stability |
| Package / wheel | `sdc-tools` / `sdc_tools-*` | **keep this phase** | renaming breaks install/docs/CI/Docker artifacts; deferred to the repository-namespace phase (see REPOSITORY_ARCHITECTURE.md) |
| Python namespace | flat modules (`checker`, `cli`, …) | **keep this phase** | no package refactor without strong evidence; documented target is `rta/` |
| Repo / GitHub | `sdc-tools` | keep (external) | not changeable from this repo |
| Windows shim | `sdc-tools.cmd` | keep + **add `rta.cmd`** | parallel alias added |
| Version | `1.3.0` | keep | release artifacts reference it |

## 7. Class E — removed

- `build/` stale wheel-build artifacts (git-ignored) containing pre-migration copies.
- No dead marketing copy was found in migrated surfaces; anything that looks stale
  should be flagged in review, not silently deleted.

## 8. Unicode rule

- **Visible brand must use `Ṛ` (U+1E5A):** website, README, reports, headings,
  CLI banners, package description.
- **Technical identifiers stay ASCII:** `rta`, `RTA_*` env vars (future),
  `rta.cmd`, URLs.
- The CLI already forces `sys.stdout.reconfigure(encoding="utf-8")`; tests decode
  subprocess output as UTF-8. Verified in `tests/test_branding.py`.
