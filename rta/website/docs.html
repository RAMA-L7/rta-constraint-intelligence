Getting started · Understanding results

Every finding is structured

Findings carry code (SDC-001…), severity, a message, the affected object and the exact source line. The trust-scope panel states how completely the input was analyzed. Readiness and coverage sections carry their own disclosures.

More on findings →

Concepts

The mental model in one paragraph

The validator preprocesses SDC into a normalized form, runs a deterministic rule engine, builds clock structure, resolves design objects (when a netlist is given), measures coverage, detects constraint interactions, computes a seven-dimension readiness verdict, and can snapshot + diff that verdict for CI. Every stage is evidence-backed; every boundary is disclosed.
